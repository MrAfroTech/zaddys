Full-size originals of the food photos (not deployed; only public/ is served).

The site uses web versions in public/images/food/: <name>.jpg (1600px wide)
and <name>-800.jpg (800px wide), JPEG quality 76, rotated upright, with all
photo metadata (including GPS location) removed. To add a photo: put the
original here with a descriptive name, make the two sizes the same way
(e.g. with the `sharp` npm package), and add it to src/data/photos.js.
